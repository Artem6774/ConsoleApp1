# Лабораторная работа №1. Задание 5. Класс Car

Выполнил: Грачев Артем

**Описание проекта:** 
Консольное приложение на C#, демонстрирующее создание класса `Car` (Автомобиль). 
Класс содержит поля (марка, номер, пробег), метод `Show()` для вывода данных и метод `SredniyProbeg(age)` для расчета среднегодового пробега.

**Результат работы:** 
В методе `Main()` создается объект (Жигули, Т144ТО, 10350 км). Выводится информация на экран, затем рассчитывается среднегодовой пробег при возрасте 2 года (5175 км/год).
